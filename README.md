# Mahendra Peramana — Developer Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in your browser.

No build tools or package installation are required.

## Before publishing
- Replace the generic GitHub and LinkedIn URLs with your own profile links.
- Add GitHub repository/demo links for your projects when ready.
- Update project status and technologies to accurately reflect current progress.
- Review the contact details before making the website public.

## Publish it
You can host this static website using GitHub Pages, Netlify, or another static hosting service.
